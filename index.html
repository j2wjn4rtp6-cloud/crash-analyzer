08 · Comparaison des modèles

Comment lire cette partie ?

Les modèles sont testés chronologiquement. Pour chaque test, le modèle reçoit uniquement les observations qui existaient avant le tour testé.

MAE : erreur moyenne absolue.
RMSE : mesure qui pénalise davantage les grosses erreurs.
R² : indique dans quelle mesure le modèle explique les variations observées. Un R² négatif signifie que le modèle n'explique pas correctement cet échantillon.

Ces chiffres ne permettent pas de déterminer quel sera le prochain multiplicateur.

10 · Comment utiliser Crash Analyzer

Étape 1 — Enregistrer les données
Tu peux ajouter les tours un par un avec le formulaire ou importer un fichier CSV.

Étape 2 — Laisser l'application analyser
Après chaque ajout, toutes les statistiques sont recalculées.

Étape 3 — Observer l'historique
Tu peux consulter les multiplicateurs, les séries, les moyennes, les médianes et la distribution.

Étape 4 — Conserver une sauvegarde
Utilise régulièrement Exporter CSV ou Sauvegarder JSON.

Étape 5 — Comprendre les modèles
La partie modèles sert à mesurer ce que les algorithmes arrivent à expliquer dans les données passées. Elle ne transforme pas l'application en système capable de connaître le prochain résultat.

11 · Avertissement final

Crash Analyzer est un outil statistique expérimental. Il ne connaît pas le mécanisme interne du jeu. Il ne connaît pas le prochain résultat. Il ne garantit aucun gain. Les statistiques présentées dépendent entièrement des données introduites dans l'application.
